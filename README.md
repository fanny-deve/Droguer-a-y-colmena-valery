# Droguería & Colmena Valery — Sistema POS web y móvil

Sistema POS con arquitectura híbrida modular y microservicio de analítica predictiva para la
Droguería & Colmena Valery (Cali). Trabajo de grado de Ingeniería de Sistemas.

## Ramas

| Rama | Propósito |
|---|---|
| `main` | Versión estable / entregable |
| `desarrollo` | Integración de frontend y backend |
| `frontend` | PWA: React + TypeScript, Service Worker, IndexedDB |
| `backend` | Base de datos (PostgreSQL/Supabase), API Java + Spring Boot y microservicio Python |

## Stack

Java + Spring Boot · Python (microservicio de proyección de demanda) · PostgreSQL · Redis Cloud ·
React + TypeScript (PWA).
